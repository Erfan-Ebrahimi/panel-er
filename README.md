# Admin Panel

React admin dashboard practice project with Material UI data grids, Recharts visualizations and Formik forms.

<p dir="rtl">پنل مدیریت تمرینی برای نمایش و ویرایش اطلاعات محصولات و کاربران.</p>

[Source](https://github.com/Erfan-Ebrahimi/panel-er)

## Stack

React · Vite · Material UI · Recharts · Formik · Yup · Axios

## What's inside

- User and product lists with data grids
- Dashboard charts and summary widgets
- User and product forms with validation
- React Router page navigation

## Local setup

```bash
git clone https://github.com/Erfan-Ebrahimi/panel-er.git
cd panel-er
npm ci
npm run dev
```

Create a production build with `npm run build`. Preview it locally with `npm run preview`.

## Project layout

- `src/pages/` — dashboard, user and product pages
- `src/components/` — charts, sidebar and widgets
- `src/pages/newUser/` — user form and schema
- `src/pages/newProduct/` — product form and schema

## Project notes

A work-in-progress practice project. Some screens use hosted API endpoints, and some routes are placeholders. The local Vite command is `npm run dev`; the `start` script references a `server.js` file that is not present in this repository.
